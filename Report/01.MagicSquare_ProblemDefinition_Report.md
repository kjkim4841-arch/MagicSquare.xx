## 1. Mom Test 결과

### 페르소나

4×4 격자, 빈칸 2개(0), 1~16, 합 34 맞추는 **학습자**

### 진짜 문제 (한 문장)

손으로 빈칸 2개를 채울 때 행, 열 합은 맞췄지만 **대각선 조건 하나를 검증에서 빠트려** 틀린 상태를 끝까지 못 잡고 **약 20분을 추가로** 썼다.

### Mom Test 증거 (과거 사실)

1. 지난번에 4×4 부분 마방진 풀고 나서, **합 맞는지 확인하는 데 시간이 많이 듦**
2. 4×4 부분 마방진 푸는 법을 **다른 사람에게 설명하기 어려움**
3. 마지막으로 중간에 멈췄을 때 **머리가 안 돌아가서** 그날은 더 안 풀었다

### 표면 문제 (솔루션 섞임 — 참고용)

| 발언/아이디어 | 솔루션 키워드 | 이번 범위 |
|---------------|---------------|-----------|
| 자동 검증 기능 있으면… | 자동 검증 | 검증 **로직**만 (범위 축소) |
| 힌트·단계별 가이드 | 힌트, 가이드 | ❌ |
| 반복 연습 기능 | 반복, 게임화 | ❌ |
| 공유·저장 기능 | 공유, SNS | ❌ |

## 2. 주제 (한 문장)

> **4×4 부분 마방진(빈칸 2, 합 34)을 손으로 풀었을 때, 행·열·대각선 조건을 빠짐없이 확인하지 못해 틀린 상태를 늦게 발견하고 시간을 낭비하는 패턴을 줄인다.**

- 솔루션 최소화: “앱”, “자동 풀이”, “힌트” 언급 없음
- Mom Test 핵심: **과거 20분 낭비** + **검증 누락(대각선)** 에만 초점

## 3. R-G-I-O

| | 내용 |
|---|------|
| **Role** | 4×4 부분 마방진을 손·코드로 다루는 **학습자** — 풀이 후 스스로 맞는지 확인하는 사람 |
| **Goal** | 채운 격자에 대해 **행 4 + 열 4 + 대각선 2** 조건을 빠짐없이 점검하고, **어느 조건이 깨졌는지** 바로 알 수 있다 |
| **Input** | 4×4 정수 격자. 1~16 각 1회, 빈칸 2개는 `0` |
| **Output** | 조건별 **통과/실패** 결과. 실패 시 **어떤 행·열·대각선**이 합 34가 아닌지 |

## 4. 성공 기준 (Mom Test 증거 연결)

| # | 성공 기준 | 연결된 증거 |
|---|-----------|-------------|
| **S1** | 4×4 격자 1판에 대해 **행·열·대각선 10개 조건**을 **한 번에** 점검할 수 있다 | 증거 1 — 확인 시간 과다 |
| **S2** | 실패 시 **“대각선 ○○ 합 = 32 (기대 34)”**처럼 **어느 조건이 틀렸는지** 명시적 출력 | 증거 2 — 설명 어려움 → 검증 단계 재현 가능 |
| **S3** | 행·열만 맞고 **대각선이 틀린** 케이스에서 **즉시** NG를 잡는다 (20분 후가 아님) | 진짜 문제 + 증거 3 — 늦은 발견 → 포기 |
