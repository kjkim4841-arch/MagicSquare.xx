## 2. 인터뷰 규칙 (세션 설정)

1. 한 번에 질문 **1개**만
2. **금지:** "만들면 좋겠어?", "이 기능 필요해?", "TDD 하면 어때?"
3. **허용:** "마지막으로 ~했을 때", "그때 몇 분 걸렸어?", "뭐 때문에 포기했어?"
4. 답이 모호하면 **추궁 1개**만
5. 솔루션 언급 시 → "그건 나중" 후 **불편/과거 행동**으로 되돌리기
